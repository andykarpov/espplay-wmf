# ESPPLAY.WMF: аудиоплеер на ESP32 для TS-Conf

[English](README.md) | Русский

Плагин для [Wild Commander](https://github.com/tslabs/zx-evo/tree/master/pentevo/soft/WC) на TS-Conf
(ZX Evolution, Karabas Mini G и другие с ESP32-S3 на SPI, ZiFi32). Играет **MP3, WAV, Ogg Vorbis,
FLAC, AAC и M4A**, плейлисты (**M3U, M3U8, PLS**) и **интернет-радио** из них. Плагин читает файл с
SD-карты и передаёт его в ESP32 по SPI. ESP32 декодирует файл и играет
его через свой звуковой выход, вместе с трекером и OPL прошивки ZiFi32.

```
+----------------- ZiFi32 Audio Player v1.1.0 -----------------+
| File:   01-kino-gruppa_krovi.mp3                             |
|--------------------------------------------------------------|
| Title:  Группа крови                                         |
| Artist: Кино                                                 |
| Album:  Группа крови                                         |
| Year:   1988      Track: 1/11       Genre: Rock              |
|--------------------------------------------------------------|
| MPEG-1 Layer III  128 kbps CBR  44.1 kHz  Joint Stereo       |
| Decoder: ESP32    Vol: █████████░ -4dB                       |
|--------------------------------------------------------------|
| ► 00:29 ██████████████░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ 01:35 |
|                                                              |
|                                                              |
| Buf ████████ 99%                                             |
|--------------------------------------------------------------|
|Spc:next P:prev <>:seek S:pause +-:vol Esc:exit               |
+--------------------------------------------------------------+
```

## Что нужно

- **Прошивка ZiFi32 с аудиоплеером** (команды `ESP_CMD_AUDIO_*` 0x90..0x97):
  [tslabs/zx-evo#97](https://github.com/tslabs/zx-evo/pull/97); для AAC, M4A и радио нужен ещё
  [#98](https://github.com/tslabs/zx-evo/pull/98) (0x98, 0x99). Пока PR не приняты, сборка лежит в
  ветке [andykarpov/zx-evo `karabas/esp32-release`](https://github.com/andykarpov/zx-evo/tree/karabas/esp32-release).
  Для Karabas Mini G прошивка есть в [karabas-go `firmware/esp32-s3`](https://github.com/andykarpov/karabas-go/tree/master/firmware/esp32-s3).
  Протокол описан в файле `pentevo/esp32/doc/esp32-audio.md` там же.
- Wild Commander 1.09 или новее (плагинная система `#10`).

## Установка

1. Положите `ESPPLAY.WMF` в каталог `WC` на загрузочном устройстве.
2. Добавьте его в секцию `[PLUGINS]` файла `WC/wc.ini` **перед** другими плагинами, которые
   открывают MP3 или WAV (`GSPLAYER.WMF`, `MEGABUZZ.WMF`). WC отдаёт файл первому плагину в списке,
   у которого есть это расширение:

   ```ini
   [PLUGINS]
   ESPPLAY.WMF
   GSPLAYER.WMF -midi_chip=2
   ```

Enter или Shift+F3 («Play on ESP32») на файле `.mp3`, `.wav`, `.ogg`, `.flac`, `.aac`, `.m4a`,
`.m3u`, `.m3u8` или `.pls` запускает его.
Если ESP32 нет или в её прошивке нет плеера, плагин показывает окно с причиной. После клавиши Enter
открывает меню Shift+Enter WC. Пункт плагина в меню F10 показывает ответ ESP32 и версию её прошивки.

## Управление

| Клавиша | Действие |
|---|---|
| `Space`, `Enter` | следующий файл |
| `P`, `Backspace` | предыдущий файл |
| `←` / `→` | перемотка на 10 с назад / вперёд (не в Ogg; за конец — следующий файл) |
| `S` | пауза |
| `+` / `-`, `↑` / `↓` | громкость, шаг 2 дБ (сохраняется для следующего трека) |
| `Esc` | выход в WC |

Когда трек доиграл, плагин переходит к следующему файлу в панели. После последнего файла
возвращается в WC.

## Плейлисты

`.m3u` / `.m3u8` (по записи в строке, названия из `#EXTINF`) или `.pls` (`FileN=`, `TitleN=`)
играется по записям; Space / P переходят к следующей / предыдущей, строка **List: n / m** показывает
номер. Запись — путь к файлу относительно каталога плейлиста (`/` или `\`, `..` работает) или URL
(радио). Текст в UTF-8 или CP1251, кодировка определяется сама. После последней записи плагин
переходит к следующему файлу панели. Если файла записи нет, плагин сообщает об этом и берёт
следующую.

## Радио

Запись плейлиста вида `http://` или `https://` — интернет-радио: ESP32 сама читает поток по Wi-Fi
(MP3, AAC, HE-AAC; формат по Content-Type; потоки Ogg и FLAC не проверялись). В **File** показывается станция, в **Title** —
название, которое передаёт станция (ICY), оба обновляются. Длительности и перемотки нет; пауза,
громкость и клавиши плейлиста работают. Оборванный поток ESP32 открывает заново. Пока идёт
подключение, видно `Connecting...`; звук начинается, когда набралось несколько секунд.

Если ESP32 не подключена к Wi-Fi, плагин подключает её к сети, сохранённой браузером
[gopher](https://github.com/andykarpov/karabas-go): `[zifi32]` `ssid=` / `password=` в
`/zifi/gopher.ini`.

## Что показывается

- **MP3:** теги ID3v2.2, 2.3 и 2.4 (название, исполнитель или исполнитель альбома, альбом, год,
  номер трека, жанр). Кодировки: UTF-16, UTF-8 и однобайтовая, которая считается CP1251. Теги
  выводятся в CP866. Обложки пропускаются без чтения. Строка потока (версия MPEG, слой, битрейт,
  для VBR средний, частота, режим каналов) и длительность берутся из кадров (для VBR из заголовка
  Xing/Info или VBRI).
- **WAV, FLAC, Ogg:** строка потока (формат, частота, разрядность, каналы) со слов ESP32.
  Длительность тоже сообщает ESP32; у Ogg её нет (`--:--`).
- **AAC, M4A:** строка потока со средним битрейтом от ESP32; длительность по нему.
- Прошедшее время считается по сэмплам, которые ESP32 уже проиграла. **Buf** — заполнение её
  входного буфера на 512 КБ.
- Если ESP32 не может декодировать файл, плагин показывает код ошибки и переходит к следующему файлу.

## Ограничения

- Плагин передаёт около 270 КБ/с: WC читает SD-карту секторами по 512 байт, дальше OTIR в SPI на
  14 МГц. Этого хватает на всё вплоть до FLAC 48 кГц / 24 бит (около 210 КБ/с). FLAC 96 кГц / 24 бит
  (около 295 КБ/с) не успевает, звук прерывается.
- У Ogg Vorbis нет перемотки и длительности. У M4A нет перемотки, и `moov` должен стоять перед
  `mdat` (`ffmpeg -movflags +faststart`). Длительность AAC — оценка по среднему битрейту.
- Радио: без HLS (`.m3u8` из сегментов); плейлист читается с SD-карты, не по URL.
- Теги WAV, FLAC и Ogg не читаются. ID3v1 (в конце файла) тоже не читается.
- Минуты на экране ограничены 99:59.

## Сборка и тесты

Нужен [sjasmplus](https://github.com/z00m128/sjasmplus) 1.20:

```
make            # -> ESPPLAY.WMF
```

Если на какой-то версии WC не работает функция `LOADNONE` (`#3D`), соберите
`sjasmplus --inc=src -DNO_LOADNONE src/main.asm`. Тогда перемотка и пропуск обложек идут через
обычное чтение, медленнее.

`make test` прогоняет плагин в симуляторе за несколько секунд. Симулятор состоит из двух частей:

- `test/wcsim.py`: Z80 из пакета [z80](https://github.com/kosarev/z80) и WC API (окна, `LOAD512`,
  `GIPAGPL`, `LOADNONE`, клавиши, счётчик 50 Гц);
- `test/espsim.py`: ESP32 на SPI, её протокол регистров и модель плеера ZiFi32. Модель держит буфер
  на 512 КБ, который опустошается в темпе потока, регистры состояния и дополнение куска DMA до 4 байт.

Тесты проверяют:

- теги и кодировки;
- что в ESP32 уходит файл с нужного места, в том числе после перемотки;
- команды, клавиши и коды выхода;
- громкость;
- окна ошибки и диагностики;
- размеры экрана и цвета.

Тестовые файлы делает `test/gen.sh` через `ffmpeg` (libmp3lame, libvorbis, flac). Тестам нужен
Python с пакетами `z80` и `mutagen`:

```
python3 -m venv venv && venv/bin/pip install z80 mutagen
make test PYTHON=venv/bin/python
```

Симулятор не заменяет проверку на железе. Звук, тайминги шины, глифы шрифта WC (`►`, `■`, `█`) и
цвета проверяются только на настоящей плате.
